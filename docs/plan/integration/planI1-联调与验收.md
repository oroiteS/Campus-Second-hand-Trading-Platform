## 2. 任务卡

### T70 smoke 全量契约断言

- **目标**：L3 的机器化主体——smoke.py 覆盖全部接口
- **前置依赖**：双线全部合并；主 worktree 环境就绪（存储 + 种子 + 前后端启动）
- **required_skills**：无
- **owns**：`scripts/smoke.py`（扩展）、`scripts/smokelib/**`
- **reads**：plan2 各联调点锚点清单；`docs/api/openapi.yaml`
- **forbidden**：`campus_backend/**`、`campus_frontend/**`、契约文件
- **验收标准**：
  1. 断言覆盖：全部 REST 接口的角色矩阵（游客/未认证/学生/管理员该得的状态码）、envelope 三键、分页默认值、403/404 关键路径、`degraded` 场景（可注入）、WS 事件握手与收发（标准库 socket.io 客户端不可用时以最小 HTTP 轮询 + flask-socketio 测试客户端替代，方式入档）；
  2. 以 **openapi.yaml 为断言依据**：路径/方法/响应字段逐项对照（契约漂移在此暴露——发现不一致属**本计划最关键产出**，判责：实现错→修复池；契约错→改契约走变更流程）；
  3. 输出：PASS/SKIP/FAIL 计数 + 每接口结论表；任一 FAIL 退出码 1；
  4. 幂等可重复（自带数据准备与清理，或标注依赖种子 `--fresh`）。
- **门禁命令**：自身即门禁
- **规模预期**：约 500 行

### T72 性能抽查

- **目标**：NFR-01/03/04 抽查
- **前置依赖**：T71 通过（数据形态稳定后压测才有意义）
- **required_skills**：无
- **owns**：`scripts/bench.py`（20 并发压测脚本，标准库线程或 httpx——若新增依赖 httpx 记 decisions.md）
