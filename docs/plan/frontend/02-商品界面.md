# b2 前端任务 · 商品界面

_版本 v1.0 · 2026-10-21 · 任务代号 `b2fe` · 分支 `feat/fe/b2-product-ui` · worktree `.worktree/b2fe` · 槽位 A（端口 5180 · `VITE_USE_MOCK=true`）· 批次计划：[02-商品域](../02-商品域.md)_

## 🎯 目标与范围

在 b0/b1 骨架之上，基于契约 0.3.0 交付商品域全部界面：首页推荐宫格、列表与筛选、详情、发布编辑、我的商品、收藏、搜索。全程 mock 运行，**与后端零依赖**（b2be/b2be2 进度无关）。同时落地四条指向 b2 的跨批次遗留。

**做**：5 个 api 模块 + 契约同构 mock、7 个页面（首页原地改造 + 6 新页）、`ProductCard` 等通用组件、`1004` 统一引导、图片懒加载、`validators` 扩展、认证页与登出降级两条 b1 遗留修复。
**不做**：下单/支付入口（b3）、聊天入口（b4）、管理后台页面（b5）、用户主页跳转（b3 `GET /users/{id}` 就绪前，卖家卡片纯展示）、路由守卫规则变更（沿用四态）。

### 涉及 FR

FR-GDS-01/02/03/04/05/06/07/08/10/11 的界面落点 · frontend-designer 基线（可达性/令牌/响应式/性能，见 [frontend/00-骨架与契约](00-骨架与契约.md)）。

## 📁 交付物清单（精确文件）

### 1. api 层五模块 + mock 五件

| 文件 | 导出函数（消费生成类型，签名随 0.3.0） |
| --- | --- |
| `api/products.ts` | `listProducts(query): Promise<Paginated<ProductSummary>>`、`getProduct(id): Promise<ProductDetail>`、`createProduct(body: ProductCreateInput): Promise<ProductDetail>`、`updateProduct(id, body): Promise<ProductDetail>`、`changeProductStatus(id, status: "on_sale"\|"off_sale"): Promise<ProductSummary>`、`deleteProduct(id): Promise<void>`、`listMyProducts(query): Promise<Paginated<ProductSummary>>` |
| `api/favorites.ts` | `favoriteProduct(id): Promise<FavoriteActionData>`、`unfavoriteProduct(id): Promise<FavoriteActionData>`、`listMyFavorites(page, pageSize): Promise<Paginated<ProductSummary & {favorited_at}>>` |
| `api/categories.ts` | `listCategories(): Promise<CategoryRef[]>` |
| `api/uploads.ts` | `uploadImage(file: File, purpose: "product"): Promise<ImageRef>`（FormData） |
| `api/recommendations.ts` | `getHomeFeed(refresh?: boolean): Promise<{items: ProductSummary[]; degraded?: boolean; degraded_reason?: string}>` |

- 搜索属 `products.ts`：`searchProducts(q, filters): Promise<同推荐结构 Paginated>`（`q` 空由调用方预检拦截，不发请求）。
- `api/mock/` 下五文件与上表一一对应，**逐字段同构**契约 schema：
  - 商品池 ≥ 60 条（覆盖 6 分类 × 5 成色 × 三档价格区间），其中 ≥3 条标题不含「机械键盘」但描述含键盘类语义（联调 AC-09 的 mock 预演）；每分类固定配色，`ImageRef.url` 用**按分类配色的 inline SVG data URI**（呼应 b6 种子占位图策略，零外网依赖）；
  - mock 场景须覆盖：首页 40 条 + `refresh` 换一批、冷启动与画像态不可区分（前端无感知）、**`degraded: true` 样例**（搜索与推荐各一，供降级提示条演示）、发布 9001 字段错误（`price` 三位小数、`image_ids` 越界）、编辑 3001、上下架 3002、删除 3001、收藏 9003、列表 `price_min>price_max` 9001；
  - `is_favorited` 状态在 mock 内可变（收藏/取消后详情与列表联动）。
- 沿用 b0 模式：每函数 `USE_MOCK` 分流；页面禁止直接 fetch/axios。

### 2. `api/http.ts` 1004 统一引导（b1 预留语义位落地）

- 响应 `403/1004`（未通过校园认证）：**当前路由非游客页时**引导至 `/certification`（携带 `from` 回跳参数），与 401 引导共用防循环逻辑；页面内已由 `RequireVerified` 守卫拦截为主，本引导兜底「守卫放行后令牌态变化」的时序缝隙。

### 3. `utils/validators.ts` 扩展（与批次计划 3.0 表同源，集中一处）

- 追加：`validateTitle`（1–50）、`validateDescription`（1–2000）、`validatePrice`（`^\d{1,5}(\.\d{1,2})?$` 且数值 ≥0.01、≤99999.99，original_price 同则可空）、`validatePriceRange`（min ≤ max）、`validateSearchQ`（1–100）；图片客户端预检（类型 jpg/png/webp、≤5MB、张数 1–9）沿用上传组件内实现。三张商品表单不各写各的。

### 4. 通用组件（`components/`）

| 组件 | 要求 |
| --- | --- |
| `ProductCard.tsx` | 概要卡：封面（**`loading="lazy" decoding="async"` + 非空 `alt`=商品标题**——b0fe 遗留落地）、价格（`original_price` 划线价对比）、成色徽章（5 档中文文案 `statusText` 统一映射）、收藏数、状态徽章（非 on_sale 置灰变体）；整卡为链接（键盘可达，触控 ≥44px）；封面比例统一（aspect-ratio 令牌） |

| `FilterBar.tsx` | 列表/搜索共用筛选：分类下拉（`listCategories` 缓存于组件级 state）、成色 5 档、价格区间双输入、排序（列表专用）；受控组件，变更即回调 |
