# planF6 · 前端：整合与打磨

_课程设计项目 · 2026-10-19 · 版本 v1.0 · 状态：待执行_

> **定位**：frontend 线第六域（终域）。不新增功能：全局一致性打磨、可访问性终审、移动端核查、演示铺装——让"能用的界面"变成"演示现场扛得住的界面"。
> **上游**：[plan0](../plan0-项目规范.md) · planF1–F5 已合并
> **对端**：无并行依赖；产出服务于 **planI1 终验**。

---

## 0. 目标与范围

### 目标

1. 全站三态（加载/空/错误）与 401/403/404 全局体验复查补齐；
2. 可访问性终审（plan0 §6.3 硬规则全站过一遍）与 320px 移动可用性核查；
3. 演示铺装：种子数据在真实界面的展示效果核对、演示脚本每步的界面就绪确认、P2 确认无残留入口。

### 范围内

全站页面的一致性修补（空态文案、错误反馈、骨架屏统一）、tokens 复查、路由与菜单核对、演示走查清单产出。

### 范围外

新功能、新页面、后端任何改动（发现后端问题走 planI1 修复池）；性能优化超出 lazy loading/图片懒载级别（深度优化在 planI1 按压测结果定）。

## 3. 任务卡（线内串行：T65 → T66 → T67）

### T65 三态与全局体验复查

- **目标**：plan0 §6.3"三态齐全"全站达标
- **前置依赖**：planF5 已合并
- **required_skills**：frontend-designer
- **owns**：`campus_frontend/src/**`（修补点分散，**改动每处 ≤10 行且只涉展示层**；超出范围的单点走新任务）
- **reads**：planF1–F5 各验收标准；plan2 §2
- **forbidden**：`campus_backend/**`、路由结构变更、状态管理重构
- **验收标准**：
  1. 逐页清单（首页/详情/发布/我的/收藏/订单×3/聊天×2/个人/认证/管理×8）核对三态，缺项补齐，清单入交付报告；
  2. 401/403/404/5xx 全局行为一致（跳转/空态/提示符合 planF1 T40 定义）；
  3. 骨架屏样式统一走 tokens；空态文案统一句式并含引导动作；
  4. 门禁全绿，无新增 lint/type 告警。
- **门禁命令**：§9 L1
- **规模预期**：约 200 行改动

### T66 可访问性与移动端终审

- **目标**：plan0 §6.3 可访问性硬规则 + 320px 可用
- **前置依赖**：T65
- **required_skills**：frontend-designer
- **owns**：同 T65 模式（展示层小修补）
- **reads**：frontend-designer skill DO/DON'T 清单
- **forbidden**：同 T65
- **验收标准**：
  1. 键盘走查清单：全站 Tab 顺序合理、焦点可见、模态焦点圈定、Esc 关闭；逐页记录；
  2. 图片 alt、图标按钮 aria-label、表单 label 关联与 `aria-describedby` 全站核查；
  3. 对比度抽查达 WCAG 2.1 AA（tokens 色板复核）；
  4. **320px 宽度核心链路可用**（首页→详情→下单→支付；聊天窗）——布局崩坏点修复；
  5. **P2 确认**：全站无"正在输入"任何残留入口；
  6. 自查报告（frontend-designer 清单逐条）入交付报告。
- **门禁命令**：§9 L1
- **规模预期**：约 200 行改动

### T67 演示铺装与前端就绪核对

- **目标**：演示脚本 12 步的界面就绪
- **前置依赖**：T66
- **required_skills**：frontend-designer
- **owns**：`campus_frontend/src/**`（铺装级微调）、`docs/plan/frontend/demo-checklist.md`（新建走查清单）
- **reads**：需求 §演示脚本、§种子数据；README 演示章节
- **forbidden**：`campus_backend/**`、`scripts/**`（种子问题记清单转 planI1）
- **验收标准**：
  1. 演示 12 步逐步在种子数据环境（主 worktree、真实后端）走查一遍，界面卡点清单化（含截图）；
  2. 占位图观感核对：商品图带标题文字、学生证"示例材料"水印清晰（生成侧问题记录转出）；
  3. 演示账号快捷方式：登录页提供演示账号提示（仅 dev 构建，读 env 配置，不入生产）；
  4. `demo-checklist.md` 产出：每步操作路径 + 预期画面 + 讲解要点骨架（供 planI1 排练用）；
  5. 门禁全绿。
- **门禁命令**：§9 L1
- **规模预期**：约 150 行 + 清单文档
