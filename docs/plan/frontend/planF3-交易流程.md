## 0. 目标与范围

### 目标

1. FR-ORD-01 ~ FR-ORD-08/09 前端半边（订单全生命周期界面）；

### 范围外

聊天（F4）；管理端订单视角（无此需求）；真实支付任何 UI（反目标）。

## 4. 任务卡（线内串行：T50 → T51 → T52）

### T50 下单与订单列表

- **目标**：FR-ORD-01/02 前端
- **前置依赖**：planF2 已合并
- **required_skills**：frontend-designer
- **owns**：`campus_frontend/src/pages/OrderCreate.tsx`（或并入详情页弹窗）、`src/pages/Orders.tsx`、`src/api/orders.ts`、相关测试
- **reads**：plan2 锚点；需求 FR-ORD-01/02
- **forbidden**：`campus_backend/**`、`src/pages/ProductDetail.tsx`（只读加购买入口，若需改动经主代理协调）
- **验收标准**：
  1. 下单确认：商品摘要 + 交易地点（可空）+ 备注（可空）；"不能购买自己商品"后端 409 的文案化（`ORD3001`→"不能购买自己发布的商品"）；
  2. 下单成功跳订单详情（待支付态）；商品被锁（409）给出"已被他人锁定"提示并返回详情；
  3. 订单列表：买到/卖出 tabs + 状态筛选 + 分页；订单卡含商品缩略图、金额、状态徽标、时间；
  4. 三态齐全；空态引导去逛逛；
  5. 门禁全绿 + tabs 切换与 409 文案测试。
- **门禁命令**：§9 L1
- **规模预期**：约 400 行

### T51 订单详情与模拟支付

- **目标**：FR-ORD-03/04 前端 + AC-11
- **前置依赖**：T50
- **required_skills**：frontend-designer
- **owns**：`campus_frontend/src/pages/OrderDetail.tsx`、`src/pages/PayPanel.tsx`（支付面板组件）、`src/components/StatusTimeline.tsx`、相关测试
- **reads**：plan2 锚点；需求 §模拟支付规则 1–5、§时序图
- **forbidden**：`campus_backend/**`
- **验收标准**：
  1. 详情：商品快照（下单时点）、金额、状态、交易地点/备注、**状态时间线组件**（每步时间）；
  2. 支付面板：点"立即支付"→pay-intent→展示固定二维码 + "使用微信 / 支付宝扫码"文案 + 渠道标识；**界面不出现任何真实支付跳转**；
  3. "已完成支付"→**每秒轮询 pay-status，最多 10 次**（需求时序图）；成功跳详情（已支付态）；轮询期间按钮禁用+计数；
  4. 30 分钟超时倒计时展示（pending_payment 态，本地计算，到时刷新状态）；
  5. 按状态渲染可用操作（待支付：支付/取消；已支付：确认完成/协商取消；已完成：评价入口；终态：无操作）；
  6. 门禁全绿 + 轮询上限与状态操作映射测试。
- **门禁命令**：§9 L1
- **规模预期**：约 450 行

### T52 确认、取消、评价与用户主页

- **目标**：FR-ORD-05/06/08/09 + FR-USR-11 前端
- **前置依赖**：T51
- **required_skills**：frontend-designer
- **owns**：`campus_frontend/src/pages/UserProfile.tsx`、`src/components/ReviewDialog.tsx`、`src/api/reviews.ts`、`src/api/users.ts`、相关测试
- **reads**：plan2 锚点；需求 §评价与信誉、FR-USR-11
- **forbidden**：`campus_backend/**`
- **验收标准**：
  1. 确认完成：二次确认（说明商品将转已售）；已支付取消：确认弹窗说明"商品回滚上架、支付置退款、需双方协商一致"（需求语义）；
  2. 评价：星级（1–5，键盘可达）+ 文字（0–500 计数）；每单一次（已评显示只读态）；提交成功后卖家信誉分位置刷新提示；
  3. 用户主页：展示名、信誉分（或"暂无"）、在售商品数、评价列表分页；同校校验（他校 404 空态）；从卖家卡与会话列表可跳入；
  4. 三态 + 可访问性（星级 aria-radiogroup）；
  5. 门禁全绿 + 评价一次性与取消确认文案测试。
- **门禁命令**：§9 L1
- **规模预期**：约 450 行
